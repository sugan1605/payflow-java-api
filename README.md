# payflow-java-api
A Java Spring Boot REST API for managing invoices and payment statuses.


## Development Environment

### Prerequisites

- Docker Desktop for macOS
- Docker Compose
- Git

### Verify Docker Installation

Run the following commands in your terminal to verify that Docker is installed and running:

```bash
docker --version
docker compose version
docker info
```

### Test Docker

Run the following command to verify that Docker can pull and run a container:

```bash
docker run --rm hello-world
```

A successful run displays `Hello from Docker!`. The `--rm` flag automatically removes the container after it exits.

### Start Docker Desktop

Open Docker Desktop and wait for the Docker engine to finish starting before running Docker commands.
